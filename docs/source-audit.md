# Source audit

การตรวจ repository ณ วันที่สร้างเว็บไซต์พบว่าไม่มีไฟล์ `sources/` หรือ PDF
ต้นฉบับ และไม่มี content/data เดิมให้ตรวจเทียบ. ดังนั้นเว็บไซต์ใช้บทสรุปที่
เรียบเรียงจากนิยามมาตรฐานและเก็บค่าตัวอย่างไว้ใน `data/worked-examples.json`.
ไม่ฝัง PDF และไม่อ้างว่าเป็นสำเนาสไลด์. ผู้เรียนควรตรวจสัญกรณ์และเงื่อนไขการสอบ
กับเอกสารอาจารย์อีกครั้ง.
