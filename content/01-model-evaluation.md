# Model Evaluation

การประเมินโมเดลต้องแยกข้อมูลฝึก (train), ตรวจสอบ (validation) และทดสอบ (test)
เพื่อไม่ให้ใช้ข้อมูลทดสอบตัดสินใจระหว่างพัฒนา. สำหรับเมทริกซ์ที่กำหนด Positive
เป็นคลาสเป้าหมาย: TP คือทายบวกและจริงเป็นบวก, TN คือทายลบและจริงเป็นลบ,
FP คือ false alarm และ FN คือพลาดตัวอย่างบวก.

สูตรสำคัญ: Accuracy = (TP+TN)/N, Precision = TP/(TP+FP),
Recall = TP/(TP+FN), และ F1 = 2TP/(2TP+FP+FN). ถ้าตัวหารเป็นศูนย์
ให้รายงานว่า “คำนวณไม่ได้จากข้อมูลนี้” ไม่ใช่ NaN หรือ Infinity.

ในการทำ k-fold cross-validation แบ่งข้อมูลเป็น k ส่วน ขนาดแต่ละ fold ต่างกัน
ไม่เกินหนึ่งตัวอย่าง แล้วใช้แต่ละส่วนเป็น validation หนึ่งครั้ง.
